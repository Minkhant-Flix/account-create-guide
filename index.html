User Guide

M-Movie Account ပြုလုပ်နည်း လမ်းညွှန်

အောက်ပါ အဆင့် ၅ ဆင့်အတိုင်းကို လိုက်လုပ်ပြီး M-Movie တွင် အကောင့်ဖွင့်၍ ဇာတ်ကားများကို အခမဲ့ ကြည့်ရှုနိုင်ပါသည်။

  1. ၁mmovie.site ရိုက်ရှာပါ
  2. ၂Burger Menu နှိပ်ပါ
  3. ၃Sign Up နှိပ်ပါ
  4. ၄အကောင့်အချက်အလက် ဖြည့်ပါ
  5. ၅OTP ဖြင့် အတည်ပြုပါ
၁
အဆင့် ၁

MMovie ဝဘ်ဆိုက်သို့ ဝင်ရောက်ပါ

  • ဖုန်း / computer browser ပေါ်တွင် mmovie.site ဟု ရိုက်ရှာပါ။
၂
အဆင့် ၂

Burger Menu ကို နှိပ်ပါ

  • Website တက်လာတာကို မြင်ရပါလိမ့်မယ်။
  • ဘေးဘက်ရှိ burger menu button ကို နှိပ်ပါ။
၃
အဆင့် ၃

Sign Up ကို နှိပ်ပါ

  • Sign Up ကို နှိပ်ပါ။ Form တက်လာပါလိမ့်မည်။
၄
အဆင့် ၄

အကောင့်အချက်အလက် ဖြည့်ပါ

  • Username နေရာတွင် မိမိထားချင်သော username (space ခံရေးလို့မရပါ — တဆက်ထဲရေးပေးပါ) ကြိုက်နှစ်သက်ရာထားပါ။
  • Email နေရာတွင် မိမိ gmail ထည့်ပါ။
  • Password, Confirm Password နေရာတွင် မိမိကြိုက်နှစ်သက်ရာ password တူကို နှစ်ခါ ရိုက်ထည့်ပေးပါ။
  • ပြီးနောက် Create Account ကို နှိပ်ပါ။
၅
အဆင့် ၅

OTP ဖြင့် Email ကို အတည်ပြုပါ

  • Verify your email လို့ ပေါ်လာပါလိမ့်မည်။
  • တစ်ချိန်တည်းမှာပဲ မိမိ gmail ထဲသို့ One Time Password ၆ လုံး (OTP) ရောက်လာပါလိမ့်မည်။
  • ထို OTP code အား ထည့်ပေးပြီး Verify နှိပ်လိုက်ပါ။
  • မူရင်း page သို့ ပြန်ရောက်သွားပြီး ဇာတ်ကားများကို တိုက်ရိုက် ကြည့်ရှု့လို့ ရနိုင်ပါပြီ။

ပြီးပါပြီ 🎉

အကောင့်ဖွင့်ခြင်း အောင်မြင်ပါသည်။ ယခု ဇာတ်ကားများကို စတင် ကြည့်ရှုနိုင်ပါပြီ။
